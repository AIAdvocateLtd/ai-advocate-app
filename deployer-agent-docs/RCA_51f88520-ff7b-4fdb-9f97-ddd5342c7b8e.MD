- The eph sandbox has NO production secrets injected, so it cannot connect to prod Mongo directly. Instead:
  - All DB reads `run_check` performs were sourced from PRODUCTION via the platform's read-only `mongo_query` tool and proven: `law_watch_records` and `law_watch_seen` collections DO NOT EXIST (empty); `lex_lessons` has 0 docs with a top-level `source_url` matching `^https://www.legislation.gov.uk/`.

The shim exposes ONLY `find`/`find_one` and raises `RuntimeError` on ANY write/forbidden op (insert/update/delete/create_index/etc) or any unexpected collection. The guard never fired.
  - Real free HTTP GETs went to www.legislation.gov.uk (9 provision data.xml + 4 feed data.feed + 0 fact data.xml = 13 requests, one attempt each). No LLM/Tavily/email calls, no crons.
- Read-op ledger captured: law_watch_records = 9× find_one (one per watchlist key); law_watch_seen = 64× find_one; lex_lessons = 1× find (the legislation.gov.uk regex). ZERO writes.
